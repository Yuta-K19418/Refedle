# Security Policy

## Supported Versions

Only the latest release of Refedle is supported with security updates. Please upgrade to the latest release before reporting an issue.

## Reporting a Vulnerability

Do not report security vulnerabilities through public GitHub Issues. Use GitHub's Private Vulnerability Reporting feature for this repository instead.

Please include:

- A clear description of the vulnerability and its potential impact.
- Steps to reproduce, including any relevant commands or input files.
- The affected Refedle version, operating system, and runtime details.
- A proof of concept or suggested remediation, if available.

We will review reports privately and coordinate disclosure and remediation with the reporter when appropriate.
